# EN
This is a plugin I developed with a hide-and-seek theme, where you play as the killer and try to find the survivors.

You can access all the commands using `/escondite`. I also implemented a setup system so you can create your own arenas using a plugin that allows you to load arenas or maps, such as MultiverseCore. It's configurable to a certain extent. It's designed to be played on Java 21 or higher versions 1.20.6. You're free to modify and distribute it for free, but please credit me as the original author. That's all. Enjoy the plugin!
